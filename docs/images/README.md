# Images

Store and README artwork. Use only royalty-free content from [samples/](../../samples/README.md), never personal files.

| Folder | Content | Size |
| :--- | :--- | :--- |
| `screenshots/` | Phone screenshots for Google Play (2-8) and the README | PNG or JPEG, 16:9 to 9:16, 320-3840 px per side |
| `feature-graphic/` | Google Play feature graphic | 1024 x 500, PNG or JPEG, no alpha |
| `animation/` | Demo GIF for the README | Short (under ~10 s), under ~5 MB |

Name files in display order, e.g. `01-search.png`, `02-video-moment.png`.
