# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub: **Security > Report a vulnerability** on the [LocalFind repository](https://github.com/bjdavey/localfind/security/advisories/new).

Include what you found, how to reproduce it, and the app version and device. You can expect an acknowledgement within a few days.

## Scope

LocalFind is fully offline and has no server, so the interesting issues are local ones: another app reading its private data, malicious files crashing the indexer, or anything that would make the app send data off the device.
